# 关于上岸知识库

上岸知识库是一个备考知识整理与资料索引站。知识内容直接在站内阅读，外部资料通过带来源和验证日期的链接进行索引。

## 内容边界

- 考研部分优先建设计算机 408 知识点和配套资料。
- 考公部分系统整理行测与申论知识，支持直接在站内连续阅读。
- 考编、教师资格证、英语四六级及其他考试，第一阶段以资料索引为主。
- 不使用未经核实的下载量、热度排行和用户评价作为装饰数据。

## 资料收录原则

每条资料至少记录：考试类型、科目、资料类型、网盘平台、来源、授权情况、更新时间、最后验证日期和链接状态。

只收录自有内容、明确授权、开放许可或官方公开资料。来源和授权情况无法确认时，不将链接标记为“已验证可用”。

## 链接状态

- **链接可用**：近期人工打开并确认可以访问。
- **待重新验证**：距离上次验证较久，或收到用户反馈但尚未复核。
- **已失效**：链接无法访问，保留记录用于避免重复收录。

## 反馈方式

当前站点没有后台提交系统。联系方式或反馈表单确定后，会在这里补充统一入口。
