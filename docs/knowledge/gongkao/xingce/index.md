# 行测知识地图

行测内容分为 6 个一级模块，并将“稳定方法”和“带年份材料”分开标记。

| 模块     | 知识范围                               | 入口                                                   |
| -------- | -------------------------------------- | ------------------------------------------------------ |
| 资料分析 | 基础术语、结构阅读、速算与五类专题     | [站内阅读](/knowledge/gongkao/xingce/ziliao-fenxi/)    |
| 言语理解 | 逻辑填空、中心理解、标题、语句与细节   | [站内阅读](/knowledge/gongkao/xingce/yanyu-lijie/)     |
| 判断推理 | 图形、定义、类比、逻辑、科学推理       | [站内阅读](/knowledge/gongkao/xingce/panduan-tuili/)   |
| 数量关系 | 数学常识、解题思想、核心题型与数字推理 | [站内阅读](/knowledge/gongkao/xingce/shuliang-guanxi/) |
| 政治理论 | 理论基础、会议、文件、讲话与热点       | [站内阅读](/knowledge/gongkao/xingce/zhengzhi-lilun/)  |
| 公基常识 | 法律、经济、历史、人文、自然科技等     | [站内阅读](/knowledge/gongkao/xingce/gongji-changshi/) |

## 怎么选起点

这是本站的使用建议：

- 想先建立可重复训练的方法链：从**资料分析**开始，再进入判断推理和言语理解。
- 想补数学短板：先看数量关系中的“解题思想”，再进入核心题型。
- 准备常识与政治：先区分理论类固定内容和带年份的时政材料。
- 准备整套考试：还需要配合[申论知识地图](/knowledge/gongkao/shenlun/)，不能只看知识文档，速度和准确率仍要靠练题建立。
