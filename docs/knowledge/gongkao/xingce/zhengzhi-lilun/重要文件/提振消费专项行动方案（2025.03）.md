# 提振消费专项行动方案（2025.03）

:::tip 内容说明
内容已按原站（SaDuck 公考知识库）完整还原：原站互动填空位置已以原文呈现，可直接通篇阅读。
:::
- 《方案》提出，要大力提振消费，全方位扩大国内需求，以增收减负提升消费能力，以高质量供给创造有效需求，以优化消费环境增强消费意愿，针对性解决制约消费的突出矛盾问题。
- **一是开展城乡居民增收促进行动**
- （1）要促进工资性收入合理增长。实施重点领域、重点行业、城乡基层和中小微企业就业支持计划。延续实施失业保险稳岗返还政策。结合形势变化加大就业支持力度，促进重点群体就业。
- （2）拓宽财产性收入渠道。
- （3）多措并举促进农民增收。健全种粮农民收益保障机制和土地增值收益分配机制，探索通过出租、入股、合作等方式盘活利用农户合法拥有的住房。实施农村低收入人口提能增收行动，持续实施农业品牌精品培育计划，实施农产品“三品一标”行动，促进绿色、有机、名特优新和地理标志农产品消费。培育新型农业经营主体，因地制宜发展庭院经济、林下经济、民宿经济，落实农机报废更新补贴政策，强化产业联农带农。
- （4）扎实解决拖欠账款问题。
- **二是开展消费能力保障支持行动**
- （1）要加大生育养育保障力度。研究建立育儿补贴制度。
- （2）强化教育支撑。扩大学龄人口净流入城镇的教育资源供给。推动高等学校学科专业设置紧密对接创新链、产业链，提高人才培养与经济社会发展需要的适配程度。
- （3）提高医疗养老保障能力。健全基本养老保险待遇合理调整机制。
- （4）保障重点群体基本生活。
- **三是开展服务消费提质惠民行动**
- （1）要优化“一老一小”服务供给。
- （2）促进生活服务消费。加强服务供给能力建设，支持服务消费场景创新、业态融合、产业集聚。
- （3）扩大文体旅游消费。深化线上线下、商旅文体健多业态消费融合，创新多元化消费场景。支持旅游景区景点、文博单位拓展服务项目，合理延长经营时间，扩大接待规模。
- （4）推动冰雪消费。
- （5）发展入境消费。有序扩大单方面免签国家范围，优化完善区域性入境免签政策。
- （6）稳步推进服务业扩大开放。
- **四是开展大宗消费更新升级行动**
- （1）要加大消费品以旧换新支持力度。
- （2）更好满足住房消费需求。持续用力推动房地产市场止跌回稳，加力实施城中村和危旧房改造，充分释放刚性和改善性住房需求潜力。
- （3）延伸汽车消费链条。
- **五是开展消费品质提升行动**
- （1）要强化消费品牌引领。聚焦商贸、物流、文旅等服务领域，分类制定提升服务品质政策，打造更多中国服务品牌。将中华优秀传统文化融入产品设计。
- （2）支持新型消费加快发展。深入实施数字消费提升行动，大力培育品质电商。开展“人工智能＋”行动，促进“人工智能＋消费”。
- （3）提高内外贸一体化水平。
- **六是开展消费环境改善提升行动**
- （1）要保障休息休假权益。鼓励带薪年休假与小长假连休，实现弹性错峰休假。不得违法延长劳动者工作时间。
- （2）营造放心消费环境。
- （3）完善城乡消费设施。
- **七是开展限制措施清理优化行动**
- （1）要有序减少消费限制。推动汽车等消费由购买管理向使用管理转变，分年限保障“久摇不中”无车家庭购车需求。
- （2）持续优化营商环境。
