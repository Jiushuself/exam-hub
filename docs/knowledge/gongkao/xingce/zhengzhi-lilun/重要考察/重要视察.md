# 重要视察

## 上海视察(2026年7月)

1. 中共中央总书记、国家主席、中央军委主席习近平 15 日在上海考察时强调，要全面践行理念，坚持，做深做细做实城市更新各项工作，不断增强居民群众的。

2. 习近平总书记强调，党中央高度重视城市工作，明确提出要建设。工作中要牢固树立和践行正确政绩观，想群众之所想，急群众之所急，制定实施有效的政策举措，坚持久久为功，把老百姓关切的事一件一件办好，持续增进民生福祉。要以“绣花功夫”不断提升小区物业管理和便民服务水平，努力让居民群众满意。

3. 习近平总书记指出。要提高社区治理水平，推动资源、服务、管理等下沉基层一线，持续为基层减负赋能。要进一步加强党建引领，积极探索社区党组织领导下的居委会、业委会、物业服务企业协调运行新模式，建设完整社区和便民生活圈，用心用情为居民做好事、办实事、解难事。

## 云南视察(2025年3月)

1. 云南要认真落实党中央关于，在中国式现代化进程中开创云南发展新局面。

2. 云南花卉产业前景广阔，要着眼全产业链，从不断深耕细作，让这一“美丽产业”成为造福群众的“幸福产业”。

3. 丽江古城有 800 多年历史，被列入世界文化遗产名录。

4. 要保护利用好木府这样的重要文化地标，引导各族群众自觉铸牢中华民族共同体意识，不断推进中华民族共同体建设。

5. 升级是高质量发展的重点工作。各地资源禀赋、基础条件等不同，抓产业转型升级要。

6. 云南要，积极发展战略性新兴产业和未来产业。

7. 要加快发展高原特色农业和文旅产业。

8. 云南区位条件独特。

9. ，加强交通物流、能源、数字信息等大通道建设，使各类开放平台成为经济发展的增长点。

10. 云南生态地位重要，要坚定不移，筑牢我国西南生态安全屏障。

11. 要，加强生态系统保护和修复，持续开展石漠化、水土流失及小流域综合治理。

12. 云南民族众多，要。

13. 是事业发展的根本保证。

## 贵州视察(2025年3月)

1. 贵州要认真落实的战略部署，坚持以统揽全局，以进一步为动力，坚定信心、苦干实干，稳中求进、善作善成，在进程中展现贵州新风采。

2. 。贵州要下定决心、勇于探索，，统筹新旧动能转换，加快传统产业转型升级，积极发展战略性新兴产业，做强做优数字经济、新能源等产业。

3. ，科学决策，精准施策，处理好的关系，实现质的有效提升和量的合理增长。要保护好生态环境，努力把转化为发展优势。

4. 一个地方的。贵州要积极融入全国统一大市场建设，坚决破除地方保护、市场分割、“”竞争，为全社会创业创新营造稳定公平透明、可预期的环境。

5. 优化营商环境要，打通制约高质量发展的堵点卡点；，引导干部。

6. 也是重要的营商环境。贵州要用好建设机遇，积极、建设，主动融入的全面开放格局。

7. 少数民族文化是中华文化不可或缺的组成部分，既要的村落、民居、特色建筑风貌，的非物质文化遗产，又要推动其，让民族特色在利用中更加鲜亮，不断焕发新的光彩。

## 吉林视察(2025年1~2月)

1. 吉林要深入落实党中央关于推动新时代东北全面振兴的战略部署。

2. 总书记指出。构建体现。要，优化创新生态，力争在一批重大科技专项上取得新突破，推动科技成果向现实生产力转化。利用冰雪、自然风光、民族风情等特色资源发展旅游业。推进长春现代化都市圈建设，注重同东北地区其他省份的协同联动，形成融合发展的格局。

3. 总书记强调。要瞄准制约，设置改革议题、生成改革方案，着力解决深层次矛盾、破除体制机制障碍。无论深化国资国企改革，还是促进民营经济发展，都要全面落实政策规定，注重典型引路。要积极一流营商环境，建设更高水平开放型经济新体制。

4. 总书记指出。吉林要以，完善强农惠农富农支持制度，统筹发展。要积极发展生态养殖，加强农产品精深加工和食品细加工，做足做活文章，构建多元化食物供给体系。推动兴业、强县、富民一体发展，促进城乡共同繁荣。加强和创新基层治理，提高文明乡风建设水平，打造平安法治乡村和宜居宜业和美乡村。

5. 总书记强调，吉林是多民族聚居地区，，着力推进中华民族共同体建设，促进各民族交往交流交融，引导各族群众树立正确的，着力开创民族团结进步新局面。要深入推进兴边富民行动，因地制宜发展边境贸易、特色产业。

6. 总书记指出，任何时候都必须紧紧抓在手上。要落实防范化解重点领域风险的各项举措，加强对自然灾害的预防预警和应对，全面排查和消除安全生产隐患，维护社会大局稳定。

7. 总书记强调，高质量发展需要高质量党建来引领。引导各级干部特别是领导干部践行正确政绩观，增强本领、担当作为、争创佳绩。坚持党性党风党纪一起抓、正风肃纪反腐相贯通，完善权力配置运行的制约和监督机制，，推动干部在遵规守纪、清正廉洁的前提下大胆干事。

## 辽宁视察(2025年1~2月)

1. 总书记对大家说，是民生大事，现在物质丰裕，过年团圆更要让大家吃得好、吃得健康。

2. 总书记指出，，一切着眼于便民、利民、安民，特别要更好地关心呵护“一老一小”。

3. 总书记指出，像鞍钢这样的国有大企业要为中国式现代化多作贡献。

4. 总书记指出，辽宁工业体系比较完备，加快建设。传统产业要，不断提升核心竞争力。培育壮大战略性新兴产业重在，因地制宜发展新质生产力。越是发展任务重，越要重视生态环境保护。

5. 总书记强调。抓改革要进一步，在建设、完善中国特色现代企业制度等方面多下功夫。现在，我们国家开放的大门越开越大，各级干部要提高在开放条件下。

6. 总书记指出，辽宁农业资源丰富、发展底子较好，。学习运用“”经验，要联系实际细化实化抓手，坚持久久为功。要明确责任、到底到边、见事见人地抓好基层治理。

7. 总书记强调，加强社会主义精神文明建设，各级都肩负重要责任。深入实施文化惠民工程，充分激发广大干部群众改革创新、振兴发展的激情和斗志。

## 海南视察(2024年12月)

1. 认真落实党中央关于海南自由贸易港建设的各项部署，科学谋划封关前后的改革开放和高质量发展工作，继续解放思想、开拓创新，攻坚克难、稳步推进，奋力谱写中国式现代化海南篇章。

2. 总书记指出。促进深度融合，推动等主导产业补链延链、优化升级。构建更加开放的，打造，加大，加强，因地制宜。加强突出环境问题整治，守护好青山绿水、碧海蓝天。促进旅游业开放合作。培育壮大新型消费。抓好海洋开发，向海洋要生产力、求新增长点，建设海洋强省。

3. 总书记强调。统筹安排好开放进度和节奏。，大力推进制度型开放，营造市场化、法治化、国际化一流营商环境。做实做优各类开放平台。精心做好各项准备工作，确保封关运作平稳有序。

4. 总书记指出。广泛开展群众性精神文明创建，努力实现物质文明和精神文明双提升。资源，增强文化创新创造活力，发展壮大文化产业。丰富城乡群众精神文化生活，持续推进移风易俗。

5. 总书记强调。民生建设，完善城乡公共服务体系和社会保障体系。。加强防灾减灾救灾能力建设，提升应对重大风险挑战能力。常态化开展扫黑除恶，依法惩治各种违法行为。

6. 总书记指出，。驰而不息抓好反腐败斗争，着力铲除腐败滋生的土壤和条件。强化对权力运行的制约和监督，教育引导干部增强拒腐防变能力。

## 山西视察(2025年7月)

1. 总书记强调，坚持稳中求进工作总基调，完整准确全面贯彻新发展理念，统筹好发展和安全，奋力谱写三晋大地推进中国式现代化新篇章。

2. 总书记说，88 年前的今天发生的，前事不忘、后事之师，到这里来就是接受精神洗礼。

3. 总书记到阳泉阀门股份有限公司进行了考察。他指出，要把握市场需求，加强科技创新，让传统产业焕发新活力。他对企业员工们说，我国的工业发展，过去是靠一榔头一锤子地敲。实业兴国，实干兴邦。

4. 总书记对下一步工作提出要求：

5. 是党中央交给山西的一项战略任务，要进一步统一思想，保持定力，坚定有序推进转型发展。要在扛牢国家电煤保供责任前提下，配套发展风电、光伏发电、氢能等能源，构建新型能源体系。要扎实推进传统产业转型升级，逐步形成体现山西特点、具有比较优势的现代化产业体系。要用好多元发展条件，优化营商环境，激发经营主体活力。

6. ，兜牢困难群众基本生活。要深化党建引领基层治理，强化社会治安整体防控，常态化开展扫黑除恶，依法打击各类违法犯罪活动，确保社会大局稳定。持续推进重点行业节能降碳，扎实开展矿山生态修复，切实维护生态安全。

7. 必须以永远在路上的坚韧和执着推进全面从严治党。要，努力营造风清气正的政治生态。要抓紧抓细深入贯彻中央八项规定精神学习教育后续工作，查摆问题要真，整改措施要实，确保取得实效。要及时总结学习教育成效和经验。

## 广东视察(2025年11月)

1. 习总书记强调，要深入学习宣传贯彻党的二十届四中全会精神，科学谋划未来5年的目标、任务和举措，以全面深化改革开放推动高质量发展，久久为功推动粤港澳大湾区建设，纵深推进全面从严治党，不断取得现代化建设新成效。

2. 金柚是梅州的特色农产品。习总书记指出，要加强科技应用，推动农文旅融合，不断延伸产业链、增加附加值，带动更多农民群众增收致富。

3. 习总书记指出，学习宣传贯彻党的二十届四中全会精神，是当前和今后一个时期全党全国的一项重大政治任务。引导广大干部群众切实把思想和行动统一到党中央决策部署上来，进一步增进共识、增强信心、增添干劲。针对干部群众关注的问题释疑解惑。广东作为经济大省和发达地区，在编制“十五五”规划时要有高站位、大格局，体现走在前、作示范、挑大梁的责任担当。
