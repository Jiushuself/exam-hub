## 本站建议的使用顺序

下面的顺序是本站根据章节关系给出的编排建议：

1. 先打开模块导读，确认该模块覆盖哪些题型。
2. 按「基础概念 → 解题方法 → 专题 → 练习或素材」阅读。
3. 直接通过左侧章节目录连续阅读，并结合题库进行限时训练。
4. 政治理论中的年份材料单独复核时效，不与稳定知识点混用。
